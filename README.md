# 🐇 Lapin de Daloa

Site vitrine responsive pour la vente de lapins.

## Fonctionnalités

- Catalogue de lapins avec photos
- Référence, race, sexe, âge, poids et prix
- Bouton « Commander sur WhatsApp »
- Message WhatsApp automatiquement prérempli
- Compatible téléphone, tablette et ordinateur
- Prêt pour GitHub Pages

## ⚠️ Numéro WhatsApp

Dans `index.html`, remplace :

```js
const WHATSAPP='2250700000000';
```

par le numéro WhatsApp réel du vendeur, sans `+`, espaces ou tirets.

## Mise en ligne

Dans GitHub : **Settings → Pages → Deploy from a branch → main → / (root) → Save**.

Le site sera ensuite disponible sur l'adresse GitHub Pages du dépôt.

## Évolution prévue

La prochaine version peut ajouter une base MySQL + API Node.js + espace vendeur afin que le vendeur puisse ajouter ses propres lapins, modifier les prix, charger les photos et passer automatiquement les animaux en « vendu ».
